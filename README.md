# حبيبة ياسر | معرض الأعمال والتصميم البصري
### Habiba Yasser — Graphic Designer & Video Editor Portfolio

موقع شخصي ومعرض أعمال تفاعلي متكامل للمصممة **حبيبة ياسر** (طالبة بكلية الفنون الجميلة بالقاهرة، دفعة ٢٠٢٨)، مبني بأسلوب بصري ريترو-ديجيتال فريد (Retro-Digital System) مع لوحة تحكم بصرية فورية (**In-Context Visual CMS**).

---

## ✨ المميزات الرئيسية (Key Features)

1. **الهوية البصرية والجمالية (Retro-Digital Aesthetic):**
   - تصميم مستوحى من واجهات الحواسيب الكلاسيكية بنكهة معاصرة مرحة ومتقنة.
   - خلفية سماء متدرجة ديناميكية تتغير بسلاسة مع حركة التمرير، ونجوم متلألئة، ومحاكاة دقيقة لأطوار القمر الفلكية عبر Canvas.
   - تأثيرات حركية دقيقة ومدروسة للملصقات والبطاقات وعناصر التفاعل.

2. **أدوات الرسم والتفاعل المباشر (Interactive Bézier Penline):**
   - شريط أدوات رسم متكامل يتيح للزائر تجربة الرسم الحر، رسم الخطوط، الأشكال الهندسية، والممحاة مباشرة فوق الصفحة.

3. **تذكرة صعود الطائرة وقراءة السيرة الذاتية (Boarding Pass & CV Viewer):**
   - بطاقة صعود طائرة ثلاثية الأبعاد تفاعلية تتضمن بيانات المصممة واعتماداتها الأكاديمية والمهنية.
   - عارض وثائق مدمج وعالي الدقة (**200 DPI**) لقراءة السيرة الذاتية مباشرة مع إمكانية التحميل والفتح في تبويب مستقل.

4. **لوحة التحكم والتعديل الفوري (In-Context Visual CMS):**
   - إمكانية تعديل كافة النصوص والصور وإضافة وحذف المشاريع مباشرة من واجهة الموقع عبر الرابط السري `/ #admin`.
   - إمكانية رفع وتغيير ملف السيرة الذاتية (PDF) من الجهاز مباشرة وحفظ التعديلات محلياً وتصدير كود البيانات المحدث.

5. **ثنائي اللغة (Bilingual Support):**
   - دعم كامل للغتين العربية (RTL) والإنجليزية (LTR) مع تبديل سلس لكافة الأقسام والمشاريع.

## 🚀 التشغيل والتطوير المحلي (Quick Start)

### المتطلبات (Prerequisites)
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- npm أو pnpm أو yarn

### خطوات التشغيل:
```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. بناء نسخة الإنتاج
npm run build

# 4. معاينة نسخة الإنتاج
npm run preview
```

## 🛠️ لوحة التحكم المستقلة (Dedicated Admin Dashboard)

* **الحساب المصرح له:** `habiba` أو `habibamarghani1@gmail.com`
* **كلمة المرور:** `132435`
* بمجرد الدخول، تشاهد حبيبة نسخة إدارية واضحة للموقع مع أقلام التعديل (`✏️`) وتلميحات صريحة ومحررات متخصصة للنصوص، الصور، ملفات السيرة الذاتية PDF، المشاريع، والتصنيفات، مع معاينة حية ومزامنة فورية وتصدير كود `portfolioData.js`.
